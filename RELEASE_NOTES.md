# Java-faithful TALE prediction with accurate per-repeat RVDs

This release substantially improves `annotale-rs` prediction accuracy, memory efficiency, and compatibility with Java AnnoTALE. The scanner now follows AnnoTALE’s core prediction strategy while retaining a lightweight Rust implementation.

## Highlights

- Eliminated false-positive calls in the validated PXO99A benchmark: **76 → 0**
- Retained **19/19 known TALEs**
- Reduced peak memory from multiple gigabytes to approximately **60–80 MB**
- Improved runtime by roughly **1.5–1.7×** across the validation set
- Added HMM-aligned, per-repeat RVD extraction
- Corrected the historical RVD residue offset that shifted canonical motifs such as `NI` and `NG`
- Added TSV output and improved threshold handling
- Simplified dependencies and removed unused code

## Java-faithful prediction pipeline

The prediction workflow now mirrors the major stages of Java AnnoTALE:

1. Rolling consensus k-mer prefiltering
2. Profile-HMM scoring of candidate windows
3. Greedy peak selection and repeat-cluster formation
4. Start- and end-domain boundary refinement
5. Stop-to-stop ORF recovery with ATG and stop-codon extension
6. HMM-aligned extraction of residues 12 and 13 from each repeat

Nested predictions are deduplicated, and candidates without a resolvable coding sequence are discarded.

## Benchmarks

For *Xanthomonas oryzae* pv. *oryzae* PXO99A:

| Metric | Previous Rust scanner | This release |
|---|---:|---:|
| Known TALEs recovered | 19/19 | **19/19** |
| False positives | 76 | **0** |
| Degenerate calls | 4 | **0** |
| Runtime | 70.7 s | **52.8 s** |
| Peak memory | 10.7 GB | **60.6 MB** |

A broader six-genome validation sweep covering three Xoo and three Xoc genomes reproduced every Java AnnoTALE call count, maintained full recall, and produced no degenerate rows. Runs required approximately **38–74 seconds** and **60–80 MB RAM**, compared with **60–122 seconds** and roughly **2.3–2.5 GB RAM** for Java AnnoTALE.

## Validation

- Prediction counts matched Java AnnoTALE across all six tested genomes.
- PthXo1/Tal2b RVD extraction matched the reviewed UniProt sequence through repeat 12, including its noncanonical third repeat.
- TalAE1 agreed closely with the published TalAE-class alignment.
- Scanner output remained unchanged after the dependency cleanup.
- All tests passed, with zero Clippy warnings.

## Compatibility note

RVD strings generated by earlier versions may contain a one-residue offset. Re-run `predict` or `analyze` with this release when comparing RVD repertoires or downstream TALE classifications.
